Safety, by design

Permission is a feature.

An agent with hands needs boundaries. Omkar-Ai uses deterministic rules — not model judgment — for the actions that matter. The model can ask. Only you can approve.

Deny, confirm, allow. Exact rules decide before the tool runs. The model cannot confirm its own request.
Checkpoints before damage. Deletes, moves, overwrites, and bulk operations are backed up first.
Undo is real. “Put it back” restores the last checkpoint. No script to write, no recycle-bin roulette.

Questions

The short answers.

Still curious? The docs cover first-run setup, voice commands, memory, safety, MCP servers, and troubleshooting.

Read the docs
Is Omkar-Ai free?
The app is free for personal and non-commercial use under CC BY-NC 4.0. AI providers may charge for API usage on their own plans. The download itself includes no key and no subscription.
Do I need my own API key?
Yes. Omkar-Ai uses your own Gemini API key for real-time voice and reasoning. Optional keys for Groq, OpenRouter, Mistral, NVIDIA, and HuggingFace can back up the router. Keys are stored locally in config/api_keys.json.
Does it work on macOS or Linux?
This download page ships Windows 10/11 builds. The application is designed cross-platform, but packaged macOS and Linux builds are not distributed here.
Will it delete files without asking?
No. Destructive operations hit the Safety Guard first. Depending on the rule, the request is denied, allowed, or paused for your explicit confirmation. Before a destructive file operation, a checkpoint is created so it can be undone.
What leaves my computer?
Prompts, audio, and any screen or webcam frames you attach go to the AI provider you configured. Memory, conversation history, skills, and API keys stay in the install folder. The website itself has no analytics or tracking.
Does it need a powerful GPU?
No. The HUD and avatar are rendered in software with Qt. A microphone, speakers, and an internet connection matter far more than the GPU.
