Six pillars

The whole system, end to end.

Every layer is designed to cover the one beside it: a fallback brain, a durable memory, guarded hands, parallel workers, and an open tool bus.

01 Dual-engine intelligence

A brain with a fallback plan.

Real-time conversation runs on Gemini Live, with Extended Thinking for hard problems and Affective Dialog for replies that sound human. When a live model hits a quota or a timeout, the router moves the job to another provider instead of dropping it.

  • 4-rung Gemini Live ladder
  • 5-provider REST router
  • Extended thinking budget
  • Quota + cooldown handling
  • Emotional voice prosody
  • Automatic fallback

02 Hermes Memory

A memory that compounds.

Facts, preferences, past sessions, and learned procedures live in a local store you can inspect and delete. The prompt carries an index; the full record is fetched only when it matters. Nothing is silently forgotten between launches.

  • SQLite FTS5 search
  • MEMORY.md + USER.md
  • Session-filtered history
  • On-demand recall tool
  • Self-learning SKILL.md

05 Safety Guard

The model can ask. Only you can approve.

Safety is deterministic, not a suggestion in a prompt. Exact rules decide whether an action is denied, allowed, or paused for a human. A confirmation token is issued by the UI — the model cannot mint one or approve its own request.

  • Deny / confirm / allow rules
  • UI-issued confirmation token
  • Backups before destructive ops
  • 50-checkpoint history
  • Undo restores real files
  • Esc stops the agent, not you

06 Extensibility

Your tools, on the bus.

Speak Model Context Protocol and Omkar-Ai can call external tools from stdio servers — SQLite, filesystem, Slack, Drive, or your own. Add a plugin for a one-off skill, or let the learning loop write a reusable SKILL.md from a task it just solved.

  • MCP stdio client
  • Prefixed external tools
  • Per-server configuration
  • Plugin loader with isolation
  • Auto-written skills
  • Progressive disclosure

Under the hood

The spec sheet, without the fog.

Voice engine
Gemini Live with Extended Thinking and Affective Dialog. 35 HD voices, emotional prosody, barge-in, and echo discrimination.
Model ladder
Four Live fallbacks plus a five-provider REST router (Groq, OpenRouter, Mistral, NVIDIA, HuggingFace) with quotas and cooldowns.
Memory
SQLite FTS5 store, MEMORY.md, USER.md, searchable conversation.jsonl, and a learning loop for SKILL.md.
Desktop control
DPI-aware SendInput mouse/keyboard, a low-level Esc hook, background UI automation via pywinauto, and an animated AI cursor.
Safety
Deterministic deny / confirm / allow rules, UI-issued confirmation, automatic checkpoints, and a 50-item rollback history.
Extensibility
MCP stdio servers, a plugin loader with crash isolation, and skills created automatically from solved tasks.
Platform
Windows 10/11 (64-bit) installer and portable builds. Microphone, speakers, and an internet connection. No GPU required.
