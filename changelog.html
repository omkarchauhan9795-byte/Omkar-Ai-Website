v3.0.0

2026-10-29

Omkar-Ai becomes an OS-level AGI: a "Hermes Mind" (persistent memory + self-learning skills) and a "Stonic Body" (Win32 hands + safety guard + subagents). Powered by Gemini 3.8 Live with Extended Thinking and Affective Dialog.

Added

  • Extended Thinking: gemini-3.8-live-extended-thinking with thinking_budget=-1 (unlimited reasoning tokens).
  • Affective Dialog: Emotional voice expression — tone, pacing, prosody match content.
  • 35 HD Voices: 30 new Gemini 3.8 voices (Zephyr, Lyra, Orion, Vega, Atlas, Nova, Cosmos, Solara, Luna, Titan, Aurora, Phoenix, Nebula, Quasar, Polaris, Vela, Rigel, Sirius, Arcturus, Capella, Procyon, Aldebaran, Betelgeuse, Antares, Spica) + 5 legacy.
  • Subagent Delegation: delegate_task tool spawns isolated background workers with own context, tools, safety guard, and planner.
  • Proactive Background Tasks: 15-min loop checks old Desktop files (>24h), pending emails, upcoming calendar events. Toggle via enable_proactive_tasks.
  • Real ESC Interrupt: Low-level hook — human ESC stops agent; agent ESC ignored (stamped with INJECTED_MARKER).
  • Blue AI Cursor (Neela): Animated cursor with breathing glow; swaps system cursors, restores on exit.
  • Background UI Automation: pywinauto click/type/read without physical mouse movement; falls back to win32_hands.
  • Checkpoints & Undo: Auto-backup before destructive ops to .omkar_backups//; undo restores; undo list shows history (50-checkpoint limit, thread-safe).
  • MCP Integration: Dynamic tool loading from external stdio servers (GitHub, SQLite, Filesystem, Memory, Brave Search, Postgres, Slack, Google Drive) via config/mcp_servers.json.
  • Multi-Provider API Router: Groq, OpenRouter, Mistral, NVIDIA, HuggingFace — automatic fallback when Gemini quota exhausted.
  • HUD Status Badges: Real-time pills: 🧠 THINKING, 🤖 SUBAGENT, 🔍 PROACTIVE, 🛡️ SAFE.
  • Log Color Coding: Subagent (purple), Safety (yellow), Checkpoint (blue).

Changed

  • Rebranded to Omkar-Ai with version foundation.
  • Live conversation model from single constant; no duplicate copies.
  • README and roadmap rewritten without edition labels or third-party credits.
  • Default HUD centrepiece is Animated Face; 3D Avatar (your photo as depth mesh) and Reactor Core available.

Fixed

  • Upgrade safety: in-place migration for config/api_keys.json and memory/long_term.json — adds/renames/preserves, never overwrites; timestamped backups before writes.
  • Self-echo guard calibration prevents false barge-in triggers.
  • Memory index budget prevents prompt overflow.

v2.4.0

2026-10-16

Five roadmap capabilities shipped in one release: interrupt by voice, conversation history, full file access, security camera, and Obsidian notes.

Added

  • Interrupt by voice (barge-in): Talking over the assistant stops it mid-sentence. Self-echo guard decides whether mic hears room or user — won't trigger on assistant's own voice. Toggle in ⚙ → CONTROLS, on by default.
  • Conversation history: Every turn appended to memory/conversation.jsonl (auto-trimmed), browsable in new HISTORY panel with live search.
  • Full file access: file_controller gains content search, archive compress/extract (zip-slip guarded), bulk copy/move/delete, "open with OS" — all confined to safe roots, every write undoable.
  • Security camera: core/security_camera.py watches webcam on background thread, mean-frame-difference motion detection, saves JPEG snapshot on cooldown, speaks alert. Tool: security_camera (start/stop/status/list).
  • Obsidian notes: actions/obsidian_notes.py treats vault as Markdown folder — list, read, search, create, append, write daily note. All paths resolved and checked inside vault.

Changed

  • Third HUD centrepiece: Your portrait as 3D mesh. core/avatar_image.py turns assets/avatar.jpg into real geometry — grid of vertices lifted by depth map, rotated in 3D, perspective-projected, lit, depth-sorted, drawn as shaded facets. Jaw drops on viseme schedule. Face located once with OpenCV Haar cascade (no MediaPipe, no model download). HUD cycle: Holo Head ↔ 3D Avatar ↔ Reactor Core.

Tests

  • Added tests/test_security_camera.py, tests/test_obsidian_notes.py, tests/test_avatar_image.py. Suite now 82 tests.

v2.2.0

2026-10-11

HUD centrepiece: 3D holographic human bust replaces human head as default, in Omkar-Ai neon-blue signature look.

Added

  • core/avatar_human.py: Realistic human bust hologram. Same real measured geometry as animated face (MediaPipe canonical face model — actual eyelids, nostrils, lips, cheekbones), reusing HoloAvatar's lit-surface + wireframe renderer. Procedural loft continues neck into broad shoulder line, chest, abdomen — full bust. Lit cyan-blue on holographic projection platform (metallic disc, segmented dark-chrome panels, concentric cyan/violet LED rings, rotating sweeps, rim lights, central projector with diagonal volumetric beams). Violet partner hue derived from theme primary. Procedural/software-rendered with QPainter — no OpenGL, no GPU, no new dependency. Speaks and listens via same viseme schedule and audio level.
  • core/avatar_crystal.py: Crystalline-bust variant kept as alternate renderer — faceted shards, same platform and animation protocol.
  • Third HUD centrepiece selectable in ⚙: cycle Holo Assistant → Animated Face → Reactor Core, survives restart.

Changed

  • Default HUD centrepiece now holographic human (hud_style default "holo"; existing users keep choice).

Tests

  • Added tests/test_avatar_human.py (silhouette reads as person, head/neck/shoulder proportions, full viseme protocol drives mouth, muting keeps it shut, renderer marks canvas) and tests/test_avatar_crystal.py — all headless.

v2.1.0

2026-10-11

Upgrade safety: installing a newer version no longer risks forgetting anything the user already had.

Added

  • core/upgrade.py: Versioned, in-place migration for config/api_keys.json and memory/long_term.json, run at startup before any setting or memory is read. Adds and never overwrites, copies renamed keys while keeping old name, preserves unknown keys (including data written by a newer build, so downgrade is safe too).
  • Timestamped backups in config/backups/ and memory/backups/ taken before any migration writes.
  • last_run_version recorded so app can tell user honestly that an update kept their settings and memory.

Changed

  • Startup runs upgrade pass before UI or memory manager touch config.

Tests

  • Added tests/test_upgrade.py covering alias migration, old-key preservation, unknown-key safety, backup creation, idempotency, and app-version recording.
