Quick Start

Get from download to first conversation in under two minutes.

1. Download & verify

Grab the Windows installer (97 MB) or portable ZIP (130 MB). Verify the SHA-256 checksum before running.

2. Install or extract

  • Installer: Run Omkar-Ai-Setup-3.0.0.exe. If SmartScreen appears, choose More info → Run anyway. Launch from Start menu.
  • Portable: Extract the Omkar-Ai folder (keep all files together). Run Omkar-Ai.exe.

3. Enter your Gemini API key

On first launch, a setup overlay appears. Paste a free Gemini API key and click Save. No key is bundled with the download.

4. Talk

Hold Ctrl+Space (or click the mic button) and speak. Try: "What can you do?" or "Open Notepad and type hello."

Optional providers: Add Groq, OpenRouter, Mistral, NVIDIA, or HuggingFace keys in ⚙ SETTINGS → 🔑 API PROVIDERS for automatic fallback when Gemini hits quota.

First-Run Key Setup

The first-run overlay asks for a single required key: gemini_api_key. Additional providers are optional and can be added later.

config/api_keys.json

All keys are stored locally in this file. You can edit it directly or use the Settings drawer.

JSON
{
  "gemini_api_key": "YOUR_GEMINI_KEY",
  "groq_api_key": "YOUR_GROQ_KEY",
  "openrouter_api_key": "YOUR_OPENROUTER_KEY",
  "mistral_api_key": "YOUR_MISTRAL_KEY",
  "nvidia_api_key": "YOUR_NVIDIA_KEY",
  "huggingface_api_key": "YOUR_HF_TOKEN"
}

Model Ladder (Voice)

The live voice engine tries models in this order, falling back automatically:

  1. gemini-3.8-live-extended-thinking — unlimited reasoning tokens
  2. gemini-3.8-live
  3. gemini-3.1-flash-live-preview
  4. gemini-2.5-flash-native-audio

Background one-shot tasks use the Multi-Provider Router (Groq, OpenRouter, Mistral, NVIDIA, HF) with cooldowns and quotas.

Push-to-Talk

Default chord: Ctrl+Space (hold to talk, release to send). Change it in ⚙ SETTINGS → CONTROLS. Global hotkey works when the window isn't focused (Windows only).

HUD Guide

The HUD is the always-on-top overlay showing system state, live audio, and activity.

Centrepieces (cycle with HUD STYLE in Settings)

  • Animated Face — Holographic head with viseme lip-sync (default)
  • 3D Avatar — Your photo as a depth-relief mesh (assets/avatar.jpg)
  • Reactor Core — Minimalist animated orb

Panels

  • Left Rail: CPU, RAM, Network, GPU meters + AI Core status
  • Centre Stage: Voice state (LISTENING/THINKING/SPEAKING), orb, waveform, last reply
  • Right Log: Live activity feed — color-coded (purple=subagent, yellow=safety, blue=checkpoint)
  • Bottom Prompt: Type commands or see the typing indicator

Status Badges

Real-time pills in the HUD header:

  • 🧠 THINKING — Extended Thinking active
  • 🤖 SUBAGENT — Background worker running
  • 🔍 PROACTIVE — 15-min loop active
  • 🛡️ SAFE — Safety Guard engaged

Memory & Skills

Hermes Memory (SQLite FTS5)

Persistent, searchable, prompt-budgeted. The index of all keys travels in the prompt; full values are fetched on demand via recall_memory.

Conversation History

Every turn logged to memory/conversation.jsonl — searchable, session-filtered, summarised for morning briefings.

Self-Learning Loop

After complex tasks (≥5 tools, error, or new skill), a background reflection creates/updates SKILL.md files in skills/ — reusable procedures captured automatically.

Skills System

Tool: skill_manage — list, view, create, patch, delete SKILL.md files. Progressive disclosure: metadata in prompt, full body on demand.

Subagent Delegation

delegate_task(task, tools_allowed?) spawns an isolated background worker with its own context, tool allow-list, safety guard, and planner.

How it works

  • Planning: Explicit tool(key=value) calls in task text, or keyword routing (web_search, file_controller)
  • Safety: Phase 5 Guard enforced inside subagent — deny stops, confirm returns "needs user's yes" to parent
  • Tools: Parent keeps conversation; subagent returns summary

Example

Voice
"Use a subagent to research the top 5 Rust web frameworks and save a comparison to my Desktop."

The subagent searches, reads, writes a file, and reports back — all while you keep talking to the main agent.

Safety & Undo (Time Machine)

Deterministic Safety Guard

Regex/exact-match rules — three outcomes:

  • deny — blocks the action, logs reason
  • confirm — requires human button/voice; model cannot confirm its own requests
  • allow — proceeds silently

Rules cover file deletion, system commands, registry edits, network calls, and more.

Confirm Banner

Visual overlay with YES, DO IT / CANCEL. Token issued by UI, not model. Voice "yes" / "no" also works.

Checkpoints & Undo

  • Auto-backup before destructive file ops (delete, move, overwrite, bulk) to .omkar_backups// with JSON metadata
  • undo tool → checkpoint_rollback() restores last checkpoint
  • undo list shows history (50-checkpoint limit, thread-safe)

ESC Interrupt

Low-level keyboard hook distinguishes human ESC (stops agent immediately) from agent ESC (ignored — stamped with INJECTED_MARKER).

MCP Integration (Model Context Protocol)

Connect external tool servers dynamically. Tools appear as prefixed functions (e.g., github_create_issue).

Config: config/mcp_servers.json

JSON
{
  "servers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "your_token" },
      "description": "GitHub repository operations"
    },
    "sqlite": {
      "command": "uvx",
      "args": ["mcp-server-sqlite", "--db-path", "C:\\path\\to\\db.sqlite"],
      "description": "SQLite database operations"
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\allowed\\path"],
      "description": "File system operations"
    }
  }
}

UI Tools

  • mcp_list_servers — status indicators
  • mcp_list_tools — browse available tools
  • mcp_call_tool — invoke directly

Open 🔌 MCP SERVERS in the drawer to test connections. Say "reconnect" after editing the config.

MCP servers run as child processes. Only configure servers you trust. The sandbox is the server's own permissions.

Troubleshooting

No sound / no microphone

  • Run python setup.py again (source) or check audio pickers in ⚙ SETTINGS → AUDIO
  • Windows Privacy → Microphone → allow desktop apps
  • Ensure speakers aren't muted in Windows Volume Mixer

SmartScreen blocks installer

  • Verify SHA-256 first (see Download page)
  • Choose More info → Run anyway

Update check fails

  • Check internet / VPN / proxy
  • Verify repo in config/update_config.json = omkarchauhan/Omkar-Ai
  • GitHub rate-limits unauthenticated checks — wait and retry with ⟳ button

App won't start after update

Re-run the installer from the release page. config/, memory/, skills/ are preserved.

High CPU / memory

  • Disable proactive tasks: ⚙ SETTINGS → TOGGLES → Proactive Tasks
  • Reduce HUD complexity: switch to Reactor Core centrepiece
  • Close unused MCP servers

Updates

Installed builds check GitHub Releases every 6 hours. Flow:

  1. Update banner appears over main window
  2. Review release notes → INSTALL UPDATE
  3. Omkar-Ai downloads installer, verifies SHA-256 against SHA256SUMS.txt, runs silently, restarts

Choose LATER to postpone. The ⟳ button in the header runs a manual check anytime.

Disable auto-checks without losing manual checks:

JSON
{
  "repo": "omkarchauhan/Omkar-Ai",
  "auto_check": false
}

require_checksum defaults to true. Do not set to false unless testing a private release that genuinely cannot publish checksums.
