Privacy Policy

Omkar-Ai is local-first by design. This policy explains what data the app handles, where it lives, and what leaves your machine.

Effective: Oct 2026 Version 3.0.0 No telemetry

Sections

Last updated: October 29, 2026

TL;DR Summary

Omkar-Ai does not collect, transmit, or sell your personal data. The application runs locally on your Windows machine. Your API keys, conversation history, memory, learned skills, and settings never leave your device unless you explicitly send them to an AI provider (Gemini, Groq, OpenRouter, etc.) as part of a request.

This website (index.html et al.) has zero analytics, zero tracking, zero cookies. It loads only Three.js from a CDN for the hero background.

Data Stored on Your Device

All persistent data lives inside the Omkar-Ai installation folder (per-user for the installer, beside the executable for portable). Nothing is written to system folders outside this directory.

All sensitive files are in .gitignore and excluded from any source distribution.

Data Sent to AI Providers

When you use Omkar-Ai, the following may be sent to the provider you configured (Google Gemini, Groq, OpenRouter, Mistral, NVIDIA, HuggingFace):

  • Your voice audio (streamed to Gemini Live for real-time conversation)
  • Your text prompts and conversation context
  • Screen captures or webcam frames only when you attach them (via screen vision or security camera tools)
  • Function/tool call arguments (e.g., file paths you ask to read, search queries)

Each provider has its own privacy policy governing how they handle this data. Omkar-Ai does not add, modify, or log provider traffic beyond what the provider's API returns.

You can switch providers at any time in ⚙ SETTINGS → 🔑 API PROVIDERS. The Multi-Provider Router falls back automatically when quota is exhausted.

Updater Network Requests

Installed builds check for updates via one unauthenticated HTTPS request to the public GitHub Releases API (https://api.github.com/repos/omkarchauhan/Omkar-Ai/releases/latest) at most once every 6 hours.

  • No API keys, prompts, memory, telemetry, or machine identifiers are sent.
  • An optional OMKAR_UPDATE_TOKEN environment variable can be set for a private repository; it is read from the environment only and never written to disk.
  • Auto-checks can be disabled in config/update_config.json without losing manual checks.
  • Updates are never downloaded or installed without your explicit click.

Third-Party Services

Omkar-Ai can connect to external MCP servers you configure (GitHub, SQLite, Filesystem, Slack, Google Drive, etc.). These run as local child processes or connect to services you authorize. Data flow to those services is governed by your MCP configuration and the respective service's policies — not by Omkar-Ai.

The website loads Three.js from cdnjs.cloudflare.com for the hero animation. No other external resources are loaded.

Your Rights

  • Access & portability: All your data is in plain, documented files (JSON, JSONL, Markdown) inside the install folder. Copy, back up, or migrate anytime.
  • Deletion: Delete memory/long_term.json to forget all facts. Delete memory/conversation.jsonl to erase history. Delete the install folder for complete removal (the uninstaller preserves data by design).
  • Correction: Edit any file directly, or tell the assistant "Forget X" / "Update my preference for Y" — it writes to memory immediately.
  • No profiling: Omkar-Ai builds no user profiles, runs no analytics, and shares nothing with the developer.

Changes to This Policy

Any changes will be posted here with an updated effective date. The app itself has no auto-update for legal documents — you'll see the new version when you visit the website.
