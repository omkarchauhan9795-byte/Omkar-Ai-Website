Installation paths

Choose how you want to run it.

Windows Installer

Per-user install to %LOCALAPPDATA%\Programs\Omkar-Ai. No admin rights. Auto-updates, Start menu entry, desktop shortcut.

  1. Download Omkar-Ai-Setup-3.0.0.exe and SHA256SUMS.txt.
  2. Verify the checksum (see above).
  3. Run the installer. If SmartScreen appears, choose More info → Run anyway.
  4. Launch from Start menu or desktop shortcut.
  5. Paste your Gemini API key on first-run setup.

Portable ZIP

Extract anywhere and run Omkar-Ai.exe. Keeps all data beside the executable. Updates are manual — download a new ZIP when prompted.

  1. Download Omkar-Ai-3.0.0-portable.zip and SHA256SUMS.txt.
  2. Verify the checksum.
  3. Extract the entire Omkar-Ai folder (do not move Omkar-Ai.exe alone).
  4. Run Omkar-Ai.exe from that folder.
  5. Paste your Gemini API key on first-run setup.
Verification

How to verify a download

Download both the artifact (.exe or .zip) and SHA256SUMS.txt from the same release.
Open PowerShell in the folder and run: Get-FileHash .\Omkar-Ai-Setup-3.0.0.exe -Algorithm SHA256
Compare the output character-by-character with the matching line in SHA256SUMS.txt.
Only proceed if they match exactly. A mismatch means the file was corrupted or tampered with — delete and re-download.

Troubleshooting

Common issues & fixes

Most install issues are SmartScreen or checksum mismatches. If the hash matches, the file is good — SmartScreen just needs reputation time.

"Windows protected your PC" (SmartScreen)
This is reputation-based, not a virus detection. First verify the SHA-256 matches. If it does, choose More info → Run anyway. The warning disappears once enough users have run the build.
Checksum doesn't match
Delete the file and re-download. A mismatch means the download was corrupted in transit or the file was modified. Do not run a mismatched binary.
Update banner says "Manual update required"
You're running the portable or source build. Auto-install is only for the installed build. Use the release page link in the banner, or switch to the Windows installer for seamless updates.
Update check fails
Check internet connection, VPN/proxy, and that repo in config\update_config.json points to omkarchauhan/Omkar-Ai. GitHub rate-limits unauthenticated checks; wait a few minutes and try the ⟳ button in the header.
No sound / no microphone
Unrelated to the installer. Run python setup.py again (source) or check the audio device pickers in ⚙ Settings → Audio. Ensure Windows privacy settings allow microphone access for desktop apps.
App won't start after an update
Download the installer from the release page and run it again. Your config\, memory\, and skills\ folders are preserved by design.
